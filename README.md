# Kirana Billing - GST B2B / B2C App

Chhoti dukan ke liye full billing app. HTML me bana hai, isliye GitHub Pages pe seedha chalega.

## Features
- Billing - Search / Barcode, Cart, Qty, Discount
- GST Bill - B2B / B2C toggle
- B2B me GSTIN, State wise CGST+SGST / IGST auto
- B2C me Inclusive of GST
- Non-GST Bill ka option
- Loose maal ke liye kg calculator - 0.25 / 0.5 / 1 / 2 / 5 kg
- Stock auto cut, Low Stock alert
- Khata Book - Udhaar, Payment Receive
- Reports - Aaj ki sale, GST Report, Recent Bills
- CSV Download
- Data browser me save hota hai - localStorage

## GitHub Pages pe kaise chalaye?
1. Is repo ke saare files upload karo
2. GitHub > Settings > Pages > Branch: main > Folder: / (root) > Save
3. Link milega: https://tumhara-username.github.io/kirana-billing-app/
4. Usi link ko customer ko bhejo, Chrome me khol ke Add to Home Screen karega to app ban jayega
